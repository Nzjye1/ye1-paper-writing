# Ye1 医学论文写作

**根据真实研究材料，撰写或补写医学论文。**

- 结合已确认的研究方案、实际结果、图表和已有材料写整篇或指定章节。
- 根据需要查找相关文献，支持中英文稿件及可编辑 Word。
- 研究事实不足时标明待核，不编造结果或研究过程。

试着说：“根据我的方案、分析结果和文献，帮我写论文初稿。”

## 安装和使用

1. [下载完整 Skill ZIP](downloads/ye1-paper-writing-skill.zip)，解压后保留完整的 `ye1-paper-writing` 文件夹。也可以点击 Code → Download ZIP，解压后找到 `skills/ye1-paper-writing` 文件夹。
2. 在 WorkBuddy、Codex、Claude Code、Cursor 等支持 Skill 的 Agent 中新建任务，将完整文件夹交给 Agent 或按软件提示导入。
3. 安装后直接告诉 Agent 想完成的任务。不同软件的具体入口和权限以实际提示为准。

可复制：

> 请读取并安装这个 Skill 文件夹：这里填写完整文件夹路径。请按当前软件支持的方式操作，完成后告诉我如何开始使用。

部分任务需要联网、Python 或文档工具，Agent 会根据环境和权限准备。患者逐行资料应留在数据所在电脑，由本地工具处理；具体能力和限制请查看 [Skill 指引](skills/ye1-paper-writing/SKILL.md)。
