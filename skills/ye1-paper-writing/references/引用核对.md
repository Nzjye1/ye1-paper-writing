# 引用核对

引用需要分别解决三件事：文献是否存在、题录与正文引用是否对应、文献内容是否支持具体论述。只有 DOI／PMID 或题录匹配不能证明文章支持某个观点；摘要、全文以及用户自带资料的阅读范围要分开记录。未获取全文时不要声称读过全文，无法核实的引用标待核，不捏造题录、出处或文献观点。

可使用随包的 MedSci `scripts/verify_refs.py` 对参考文献题录做辅助核对。先在本地单独整理**公开参考文献列表**为 `.bib`、`.tsv`、`.md` 或 `.txt`，不要把患者数据、未发表稿件内容或私人信息作为检索词。脚本会联系 PubMed、Crossref、DOI 注册服务及可选 OpenAlex；宿主不允许联网时可用 `--offline` 提取，所有未查明条目仍为待核。

```sh
python scripts/verify_refs.py references.bib --project-root 任务工作目录/refs-audit --no-openalex
```

工具在指定工作目录写入 `qc/reference_audit.json`；使用新目录，避免覆盖已有核查文件。默认仅按已识别的公开 PMID／DOI 联网核对，**不将题名或稿件正文自动发送到题名检索**；缺少标识的条目会保留 `UNVERIFIED`。需要按题名补查时，Agent 先在本机核对并单独整理仅含公开参考文献的 `.txt`、`.bib` 或 `.tsv`，确认没有稿件正文、作者待办或其他未公开材料，再对该列表使用 `--allow-title-lookup`；完整 DOCX 不允许启用该选项。Word 文献标题无法识别时，先提取公开文献列表，不把整篇稿件当作题名。核对解析数量是否与实际参考文献相符，关注每条 `status`、`note` 和 `evidence`。`UNVERIFIED` 是未核实，不是正确；`FABRICATED` 或 `MISMATCH` 是需要复核的程序提示，不直接作为断定造假的依据。脚本能处理的格式、文献库收录与网络状况均有限，无法解析或无法联网时根据可用来源继续，说明缺口。

对于承载核心论证、方法或重要数字的引用，应阅读实际可取得的原文或摘要，判断研究对象、方向、结果及局限是否与所写内容对应；来源不能支持的句子应修改或保留待核，不能用看似相似的文献替换成事实。发表年份、撤稿及更正状态按实际题录和公告核实，不凭 PMID 数字范围推定；离线无法核实就标待核。
