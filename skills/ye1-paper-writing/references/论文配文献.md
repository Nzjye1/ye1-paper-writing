# 给论文配足合适的文献

以本稿研究问题和需要支持的论述为中心，主动找到、阅读并选用足够相关的真实来源，不机械规定统一的最低篇数。完整原创研究文献很少时，检查疾病或临床背景、指南、同类研究、不同发现以及必要方法是否漏了；结合实际主题和同类型论文继续补查。短文、病例、稀有主题和期刊限额不同。医生明确提出文献数量时尽力满足，但不加入无关或无法核实的文献。

## 把文献调研接回当前论文

1. 先用已提供的同一研究主题文献、文献库和可读全文；确定哪些论述仍缺依据。根据研究人群、设计、干预／暴露、结局及讨论重点设计多组公开检索词，包括相关、不同结果及近期进展。围绕写作补查即可，不强制启动完整系统综述或让医生重述已知材料。医生给的文献是线索而不是数量上限；根据正文需要补充。
2. 如果 **Ye1 医学文献调研**在当前宿主实际可用，以当前研究问题、论文版本、已有文献和缺口为输入调用它；要求它筛选相关研究、尝试取得可用全文，返回题录、能支持的内容、阅读范围和本地资料路径，再直接用于本稿。若不可用，使用下方随包复用的同一检索和全文工具；也利用宿主现成医学、联网和文献工具。不能仅凭产品名称声称已自动调用，也不自动安装其他 Skill。
3. 先按相关性选文献，再积极找全文：使用已有文件、PMC 可访问版本，按宿主能力继续查看出版商网页、Europe PMC、开放文献库及用户已有机构访问权限。必要时从同主题论文的参考文献、被引研究和指南追查候选；核对版本与同一研究身份。单次 PubMed 截断或某一篇没有 PMC 文件都不是停止检索的理由；可调整查询、继续分页或补充其他适用来源。不要为了方便取得全文而忽视相关的重要研究。
4. 核对文献是否真实、出版状态、更正／撤稿提示、研究对象和结论是否对应论述。**摘要有清楚、足够的信息时，可以在摘要实际支持的范围内引用该篇已发表论文**，例如准确归纳其摘要报告的研究对象和主要结果；记录实际只读到摘要，不宣称阅读全文，也不从摘要推断未呈现的方法细节或机制。要判断的信息确实需要全文时，继续找其他可用来源或对论述作相应调整；只有努力后仍无法解决的具体事实才标待核或向医生提出需要的那一篇。
5. 文献与对应论述一一匹配；使用目标期刊要求及可用文献管理工具处理格式。不凭记忆编造题录，不把普通文字编号称作 Zotero 或 EndNote 引用域。核对目标期刊对 AI 辅助和参考文献的现行规定。失败或未覆盖部分如实记录，但不要把个别未获全文变成整篇不能继续写的理由。

## 不安装其他 Skill 时：用随包同源工具

以下代码复制自 Ye1 医学文献调研，使用 Python 标准库，Agent 根据实际任务和可用网络执行；查询文件由 Agent 自行创建，医生不需要写命令。公开检索仅发送必要的关键词、PMID／DOI，患者资料和未发表论文正文不要发往检索服务。

1. 用 `scripts/literature/pubmed_search.py` 分页获取题录及可用摘要。JSON 示例：

```json
{"topic":"本稿研究问题","page_size":100,"queries":[{"name":"related","term":"公开的相关研究检索式"},{"name":"different-findings","term":"公开的不同发现检索式"}]}
```

运行 `python scripts/literature/pubmed_search.py --queries searches.json --out 任务目录/检索结果`。`receipt.json` 记录各查询命中数、分页、错误及是否完整；`candidates.csv` 初始为待筛选。结果太宽时自行缩小主题或分批，不把脚本上限、失败或只看第一批说成已查全。无需一次检索所有医学论文，围绕实际缺口继续找到相关依据。
2. 根据题录、摘要和真实判断筛出适合本稿的候选；可用随包 `scripts/literature/screen_queue.py` 记录判断和阅读范围，它不会替代阅读。建立或使用经授权的本地主题库，然后在新主题中执行：

```sh
python scripts/literature/local_library.py init --topic 任务目录/文献库/主题 --name 当前论文主题
python scripts/literature/local_library.py import --topic 任务目录/文献库/主题 --candidates 任务目录/检索结果/candidates.csv
python scripts/literature/local_library.py fetch --topic 任务目录/文献库/主题 --ids PMID:123456,PMID:234567
```

将示例 ID 替换为真实且经筛选的候选。全文工具从 PMC 官方开放数据集优先保存 PDF，否则尝试全文文本或 XML，并记录来源、版本和许可；它不保证每篇都有 PMCID、开放版本或可用全文。无 PMCID、未在 PMC 找到或下载失败时，继续检查其他来源；下载成功也不等于已经阅读。若已有合适主题库，先确认归属并保留已有记录；不要覆盖原文件或旧报告。
3. PMC 不是唯一来源：对于未取得全文的公开 PMID／DOI，Agent 可先生成 `{"items":[{"pmid":"真实PMID"},{"doi":"真实DOI"}]}`，运行 `python scripts/literature/find_fulltext_links.py --input ids.json --out links.json`，查 Europe PMC 记录里的全文链接及可用状态；一次最多 50 条。工具只返回线索，不会下载或阅读全文。再根据宿主实际能力访问出版商、Europe PMC、可信开放仓储和用户有权使用的机构数据库；可采用 Unpaywall 等服务提供的开放版本线索，按实际可用条件访问。核对 PMID／DOI、版本和预印本状态，按授权访问；链接出现不等于全文已获取或已阅读。确实不可得时，利用可靠摘要或可支持同一论述的其他研究继续写作，并为无法解决的关键缺口标明实际情况。

`scripts/ye1_pubmed.py` 也可用于快速候选预览，但每组只取设置的有限数量；`partial_sample` 表示截断。缺口仍在时，应使用上面的分页检索及其他来源继续，不要因为预览取样结束就停止。题录核对详见[引用核对](引用核对.md)。
